- 表白/祝福

## 我们支持以下功能

- 向表白墙上发表文本
- 匿名！
- 在文本中嵌入HTML与LaTeX来美化文本与数学公式
- 为文本点赞

## 而且我们正在努力开发

- 支持Markdown语法
- 支持发送图片
- 支持对文本进行评论
- 使用标签分类文本，并支持搜索
- 支持举报

## 也有一些规则

- 内容不涉及学校管理层面
- 不发布敏感、引战、人身攻击内容，遵守法律法规与校规校纪
- 禁止“开盒”与人身攻击，严禁造谣、诽谤与不实信息
- 不得讨论社会/政治/宗教等外部争议的敏感话题

本站仅提供平台，所有投稿内容不代表本站立场。投稿者需对自己言论负全部法律责任。

如果你违反这些规则，那么我们将会删除你的消息！也欢迎在以后举报功能加入后，举报违反这些规则的言论！
